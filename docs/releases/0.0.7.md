# 0.0.7 Release Notes

发布日期：2026-10-24

## 主要改进

### Heyue Bootstrap 绑定修复

- stable `latest.json` 与不可变 `manifest.json` 现在必须匹配相同的 `revision`、`releaseId` 和 `publishedAt`。
- Bootstrap 校验完成后，将固定的 `--tag`、`--revision` 和 `--interactive` 传给归档内安装器。
- 安装器不会因为 Bootstrap 与交互器之间 stable 指针变化而切换到另一版本。
- 既有 `/api/downloads/heyue/bootstrap.py` 和 `/api/downloads/heyue/bootstrap/install.sh` 入口保持不变。

## 兼容性与数据

- 不改变 SQLite 数据结构或已有发行对象。
- 不修改 Heyue `stable/latest.json`；该指针仍由 Heyue 发布流程独立管理。
- 保持匿名 HTTPS 下载、`X-Fuwu-SHA256`、`SHA256SUMS` 和不可变版本路径契约。

## 验证

- `uv run --frozen pytest -q`：127 passed，92 subtests passed。
- Shell Bootstrap `bash -n` 通过。
- 内嵌 Python Bootstrap 编译通过。
- 回归测试验证固定 `--interactive`、`--tag`、`--revision` argv，并拒绝 manifest 身份不匹配。
