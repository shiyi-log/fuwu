# 0.0.4 发布说明

0.0.4 增加了项目级 GitHub 授权、从 GitHub Release 下载到受保护 staging 的完整链路，以及根目录配置和成员管理能力。

## 主要变化

- 项目管理员可以为绑定仓库授权 GitHub Personal Access Token。服务端通过 GitHub API 校验账号和仓库访问权限，令牌只保存在受保护的 `0600` 凭据文件中，不进入 SQLite、日志或 API 响应。
- 发布管理页面支持按项目和 tag 获取 GitHub Release 资产。服务端限制 GitHub HTTPS 域名，拒绝 draft/prerelease，校验 `SHA256SUMS`、manifest、大小和摘要；下载后的 staging 仍需显式提交普通发布任务。
- 根目录 `fuwu.config.json` 提供非敏感的超级管理员初始化配置。`bootstrap-config` 从部署环境变量读取初始密码，不保存明文密码。
- 超级管理员可以注册成员、维护角色/权限/项目范围、停用账号和重置成员密码；成员可以自行修改密码。敏感账号变更会立即撤销既有会话。

## 兼容性与验收边界

本版本保持既有 SQLite 数据、发布接口和 v1 manifest 兼容，不包含跨数据库迁移。后端测试、Django 检查、前端 typecheck/build、GitHub Actions 和 GitHub Release 资产校验分别提供独立证据；真实对象存储、云端部署和生产环境仍需单独验收。
