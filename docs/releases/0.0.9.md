# Fuwu 0.0.9

- Discover the newest published GitHub Release automatically from the registered project repository.
- Let release publishers synchronize a newer release through protected staging, manifest and SHA256 validation, immutable object uploads, and latest pointer verification.
- Keep latest metadata reads available to scoped read-only release users; require publish permission for synchronization.
- Accept multi-digit hosted project version components such as `1.0.14`, while keeping Fuwu's own one-digit carry sequence.
- Prevent downgrade, duplicate publication, and replacement of same-version content with different assets.
- Refresh the release list after successful or recovered synchronization, including when an earlier browser request timed out after server completion.

This release does not change the SQLite schema. Existing manual staging and explicit publish operations remain available.
