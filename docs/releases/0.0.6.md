# 0.0.6 Release Notes

发布日期：2026-10-22

## 主要改进

### GitHub 授权全局化

- **统一授权管理**：将 GitHub 账号授权从项目级别改为全局级别
  - 一次授权后，所有项目的远端发行下载都可以使用
  - 简化了授权流程，避免每个项目单独配置
  - 授权配置移至系统设置页面，集中管理
- **后端优化**：
  - 重构 `GithubAuthorizationStore` 存储逻辑，从项目级别改为全局级别
  - 简化 API 接口，移除项目相关参数
  - 旧项目级路由不再作为兼容入口；部署时需要在系统设置重新授权
- **前端调整**：
  - 从项目设置页面移除 GitHub 授权部分
  - 在系统设置页面添加统一的 GitHub 授权配置
  - 更新 API 调用以适配新的接口

## 技术栈

- 后端：Python 3.14 + Django 5.2 + uv
- 前端：Vue 3 + Vben Admin 5.7.0 + Ant Design Vue
- 部署：Docker Compose + MySQL 8.4 + Redis 7.4

## 升级说明

从 0.0.5 升级到 0.0.6：

1. 拉取新镜像：
   ```bash
   docker-compose pull
   ```

2. 重启服务：
   ```bash
   docker-compose up -d
   ```

3. 迁移说明：
   - 旧项目级凭据文件不会自动迁移为全局授权，也不会被当作有效全局凭据读取
   - 在系统设置中重新提交全局 PAT 后，再按部署保留策略清理旧凭据文件
