# Fuwu 0.1.3 发布说明

发布日期：2026-11-27

## 主要更新

### SMTP 配置工具

- 新增 `scripts/detect_smtp_config.py` 自动检测工具
  - 支持 30+ 邮箱服务商：QQ、163、Gmail、Outlook、企业邮箱等
  - 自动生成 `.env` 格式配置
  - 提供交互模式、批量检测和服务商列表查询
  - 包含应用专用密码和授权码提示

### SMTP 文档完善

- 完善 `docs/SMTP_GUIDE.md` 配置指南
  - 添加常见邮箱服务商配置示例
  - 新增自动检测工具使用说明
  - 补充测试脚本和故障排除指南

### API 增强

- 新增 `/api/downloads/{project}/versions.json` 端点
  - 列出已发布的稳定版本
  - 支持受控降级选择
  - 按数字版本号排序（1.0.10 > 1.0.9）

## 升级说明

从 0.1.2 升级到 0.1.3：

1. 拉取最新代码：`git pull origin main`
2. 更新 Python 依赖：`uv sync --frozen --all-extras`
3. 更新前端依赖：`cd frontend && pnpm install --frozen-lockfile`
4. 重启服务

无需数据库迁移或配置更改。
