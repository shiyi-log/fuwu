# 0.0.3 候选版本说明

本候选版本完善通用项目发行管理服务的存储配置和项目文档能力。

## 变更

- 修复 Django 适配器未注册对象存储设置路由的问题。
- 系统设置支持在服务端安全保存 S3 兼容存储凭据；凭据不进入数据库、日志、任务或 API 响应。
- 管理界面只展示脱敏 Access Key 提示，Secret Access Key 与 Session Token 保存后不回显。
- 项目资料可记录通用公共 API 说明和构建方式。
- 完善中文 API、部署、发行一致性、项目台账和版本记录。

## 兼容性与迁移

- 项目版本字段保持三段单数字格式。
- v1 发行 manifest、不可变对象路径和匿名 HTTPS latest/制品读取保持兼容。
- SQLite 表初始化保持幂等；本版本不执行向 MySQL 或 Redis 的业务数据迁移。

## 验证状态

此说明对应本地候选内容，不代表正式发布。后端测试、Django 与迁移检查、前端固定版本构建、GitHub Actions 和真实对象存储验收应分别记录结果。
