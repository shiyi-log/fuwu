# 0.0.5 Release Notes

发布日期：2026-10-22

## 主要改进

### 前端安全性增强

- **统一会话过期处理**：重构了前端认证流程，将会话过期处理逻辑集中到 `handleSessionExpired()` 方法
- **改进重定向安全**：引入 `sanitizeRedirectPath()` 函数，防止开放重定向漏洞
  - 过滤非法的重定向路径（如包含协议、双斜杠、路径穿越等）
  - 统一处理登录后的重定向逻辑
- **优化错误提示**：避免在登录失败时重复显示错误消息

### CI/CD 流程改进

- 维持现有的严格 CI/CD 流程：
  - 文档结构检查
  - Python 3.14 + Django 完整测试
  - 前端 TypeScript 检查和构建
  - 源码打包和 SHA256 校验
  - 精确提交的 CI 证据复用

## 技术栈

- 后端：Python 3.14 + Django 5.2 + uv
- 前端：Vue 3 + Vben Admin 5.7.0 + Ant Design Vue
- 部署：Docker Compose + MySQL 8.4 + Redis 7.4

## 升级说明

从 0.0.4 升级到 0.0.5：

1. 拉取新镜像：
   ```bash
   docker-compose pull
   ```

2. 重启服务：
   ```bash
   docker-compose up -d
   ```

3. 前端会话处理已改进，无需额外配置
