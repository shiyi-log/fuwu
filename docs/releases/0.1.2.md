# Fuwu 0.1.2

- Keep the default root configuration file and relative GitHub credential paths under `FUWU_INSTALL_ROOT` when a stable installation root is configured. Switching the active release then preserves the host's existing configuration and authorization files.
- Preserve explicit `FUWU_CONFIG_FILE` and `FUWU_GITHUB_CREDENTIALS_FILE` overrides. Deployments without an installation root keep their existing source-root path behavior.
- Keep the online update API and release bundle format compatible with 0.1.1. This release adds no database schema migration.

Publish only after validation of the exact source commit. Online installation still requires the protected host layout, `current` link, static resource link, and managed service described in the deployment guide.
