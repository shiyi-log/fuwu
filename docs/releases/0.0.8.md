# 0.0.8 Release Notes

发布日期：待发布

## 主要改进

### 修复 Heyue Shell Bootstrap 的交互终端继承

- 修复 `/api/downloads/heyue/bootstrap/install.sh` 使用 heredoc 启动 Python 时吞掉标准输入的问题。
- Python Bootstrap 现在先写入受保护的临时文件，再以文件路径启动，Heyue 交互安装器可以继承用户的真实 TTY。
- 保持 stable/latest、manifest、`SHA256SUMS`、匿名 HTTPS、固定 `--tag`、`--revision` 和 `--interactive` 参数契约不变。

## 兼容性与数据

- 不改变 SQLite 数据结构或既有 Heyue 发行对象。
- 不修改 Heyue stable/latest 指针。
- 临时 Python 文件在 Shell Bootstrap 退出时清理，不写入仓库或发行记录。

## 验证

- `uv run --frozen pytest -q`：133 passed，94 subtests passed。
- Shell Bootstrap `bash -n`、Python 编译、`uv lock --check` 和 `uv build` 通过。
- 新增 PTY 回归测试确认 Python 子进程看到 TTY；远端部署和实时安装复验在发布后执行。
