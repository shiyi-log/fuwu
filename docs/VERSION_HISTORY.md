# fuwu 版本记录

本文档记录可交付版本、重要变更、API 影响和验证结果。它与 Git 标签、发布说明和部署记录相互对应，但不替代这些记录。

## 版本策略

- 版本号采用 `MAJOR.MINOR.PATCH` 形式。
- `MAJOR`：存在不兼容的 API 或数据变更。
- `MINOR`：向后兼容地新增功能或接口。
- `PATCH`：向后兼容的缺陷修复、文档或构建修订。
- 未发布内容先记录在 `Unreleased`，正式发布时迁移到具体版本并填写 Git 标签、发布日期和验证证据。
